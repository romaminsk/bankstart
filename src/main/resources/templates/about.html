О проекте BankStart

Цель

BankStart — это инструмент для оценки финансовой устойчивости малого бизнеса. Мы помогаем предпринимателям понять вероятность успеха их бизнеса на горизонте 12 месяцев.

Метод Monte Carlo

Мы используем метод Monte Carlo — статистическое моделирование, которое прогоняет 1000 вариантов будущего с учётом:

  • Случайных колебаний выручки
  • Сезонности бизнеса
  • Налоговой нагрузки
Технологии
  • Backend: Java 21, Spring Boot 3.2
  • Frontend: Thymeleaf, Bootstrap 5, Chart.js
  • Database: PostgreSQL 15 (H2 для разработки)
  • Архитектура: Layered (Controller → Service → Repository)
